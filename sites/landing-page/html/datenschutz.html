3. Hosting und Server-Logfiles

Diese Website wird bei der IONOS SE (Elgendorfer Str. 57, 66482 Zweibrücken) gehostet und auf einem eigenen Server betrieben.

Bei jedem Zugriff auf diese Website erhebt das System automatisch Daten und Informationen in sogenannten Server-Logfiles:

  • IP-Adresse des zugreifenden Geräts (ggf. gekürzt)
  • Datum und Uhrzeit des Zugriffs
  • Name und URL der abgerufenen Datei
  • übertragene Datenmenge
  • Browser-Typ und -Version
  • Betriebssystem des Nutzers

Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an der sicheren und stabilen Bereitstellung der Website sowie der Abwehr von Angriffen).

Speicherdauer: Die Logfiles werden nach spätestens 14 Tagen automatisch gelöscht. Eine Zusammenführung dieser Daten mit anderen Datenquellen findet nicht statt.

4. Lokaler Speicher im Browser (localStorage)

Die auf dieser Website angebotenen Anwendungen speichern Ihre Eingaben und Einstellungen ausschließlich im lokalen Speicher Ihres eigenen Browsers („localStorage“). Diese Daten verlassen Ihren Browser nicht, werden nicht an den Server übertragen und sind nicht mit anderen Datenquellen verknüpfbar.

Gespeichert werden ausschließlich technisch notwendige bzw. von Ihnen ausdrücklich gewünschte Nutzungsdaten, z. B.:

  • zuletzt gewählte Aktivität auf der Startseite
  • Alarme, Timer-Dauer und Pomodoro-Einstellungen (Punctum)
  • Garten- und Beetrocken-Daten (Gartenjournal)

Rechtsgrundlage: § 25 Abs. 2 TDDDG — die Speicherung erfolgt auf Ihre ausdrückliche Anfrage hin (Sie wählen die App, stellen den Timer ein oder legen Daten an) bzw. ist für die von Ihnen gewünschte Funktion zwingend erforderlich.

Löschung: Sie können diese Daten jederzeit über die Einstellungen Ihres Browsers („Browserdaten löschen“) entfernen. Beim Gartenjournal können die Daten zusätzlich über die Export-/Import-Funktion gesichert werden.

5. Punctum (punctum.pompui.de)

Die Stoppuhr, der Timer, der Wecker und der Pomodoro-Modus verarbeiten alle Zeitdaten ausschließlich lokal in Ihrem Browser. Es werden keine Zeiterfassungs-, Alarm- oder Eingabedaten an den Server übertragen.

6. Gartenjournal (gj.pompui.de)

Alle Garten- und Beetdaten werden ausschließlich lokal in Ihrem Browser gespeichert (localStorage) und können von dort als JSON-Datei exportiert werden. Es findet keine Übertragung an den Server oder Dritte statt.

7. SnapOtter (snapotter.pompui.de)

Auf snapotter.pompui.de betreiben wir die Open-Source-Anwendung SnapOtter (Community Edition). Bei der Nutzung werden:

  • ein Benutzerkonto (Benutzername, Passwort-Hash)
  • die von Ihnen hochgeladenen und erzeugten Dateien
  • technische Protokolldaten

auf unserem eigenen Server in einer lokalen Datenbank gespeichert. Die Produkt-Analyse (Telemetrie) von SnapOtter ist dauerhaft deaktiviert — es werden keine Nutzungsstatistiken an Dritte übermittelt. Dateien und Datenbank verlassen den Server nicht.

Die Anwendung steht unter der AGPL-3.0-Lizenz; der Quellcode ist über die im Impressum verlinkten Stellen abrufbar.
